 # OpenCourts Backend
A python web service for OpenCourts.

## Setup

```bash
cd backend
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
```

A Flask application has not been created yet.
